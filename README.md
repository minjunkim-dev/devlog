# devlog

iOS 개발 경력 4년 4개월. Rust로 API를 만들고 있고, 다음 단계로 워커와 부하 테스트를 붙입니다.

매일 한 일, 내린 결정과 이유, 막힌 것을 짧게 기록합니다. 다듬은 글은 [Tech Notes](https://minjunkim-dev.github.io/)에 씁니다.

## 규칙

- 매일 `YYYY/MM/DD.md` 하나. 나쁜 날은 3줄만 써도 됩니다.
- "결정과 이유"는 꼭 씁니다. 블로그 글과 면접 답변의 재료가 됩니다.
- 실패와 막힌 점도 그대로 씁니다.
- 측정값은 측정 조건(환경, 횟수, 데이터)과 함께 씁니다.
- 회사 코드와 내부 정보는 쓰지 않습니다.
