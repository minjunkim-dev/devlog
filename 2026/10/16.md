# 2026-10-16

- 한 것: 흩어진 이력서·포트폴리오 자료를 비공개 Git 저장소 하나로 모았다. 사실은 정본 파일 한 곳에서만 고치고, 이력서는 정본에서 골라 조립한다. 커밋할 때마다 점검 스크립트가 정본에 없는 수치와 금지 표현을 막는다.
- 결정과 이유: 버전을 폴더 복사(v4, v5…)가 아니라 Git 태그로 관리한다. 폴더를 복사했더니 한쪽을 고쳐도 다른 쪽에 옛 문장이 남았다. 기술 블로그와 개발 일지는 분리한다. 블로그는 다듬은 글, 일지는 매일의 기록이라 품질 기준이 다르다.
- 막힌 것: private 저장소의 GitHub Actions가 계정 결제 문제로 시작되지 않았다. 같은 절차(점검 → 빌드 → Release 첨부)를 로컬 스크립트로 옮겼다. Release 업로드는 한글 파일명에서 404가 나서 영문 이름으로 복사해 올렸다.
- 다음: 매일 이 저장소에 3줄 이상 쓴다. Rust 사이드 프로젝트의 첫 단계 범위를 정한다.
